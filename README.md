# andrei-popescu-resume

Code for online resume, fork of [rajaprerak](https://rajaprerak.github.io/) personal portfolio ![MIT license](https://img.shields.io/:license-mit-blue.svg)

## Features 📋

⚡️ Fully Responsive\
⚡️ Valid HTML5 & CSS3\
⚡️ Typing animation using `Typed.js`\
⚡️ Easy to modify

## Sections 📚

✔️ About (declaration of intent, highlights, interests and hobbies) \
✔️ Education (high school, university, Online Certification) \
✔️ Experience (break down recent and heritage) \
✔️ Skills \
✔️ Resume (classic pdf) \
✔️ Contact Info

## Tools Used 🛠️

**GitHub Pages** host static website (HTML, CSS, JS).
