## intent

purpose of this repo is to use the `rajaprerak.github.io` html template and styling to create a resume web site of my own i can host on public github with github pages.
instead of having a lot of content in index.html, my personal preference is to keep a structured JS object in JSO i could easily maintain when i switch employers; change the object vs editing data and html markup; have jquery add data to DOM nodes by id once resume JS object is modified.
before claude init, strategy was to have all the structured data in RJSN and incrementally move sections out of the JSON to resume JS window.
i am happy with current state.
