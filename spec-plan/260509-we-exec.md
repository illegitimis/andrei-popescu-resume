These came up during the comma-split rule and were resolved per the plan's accepted-casualty clause (plan §"Decisions" #5). Mentioning here so the user can post-process if any pill renders awkwardly:

3. **Microsoft** `storage/data: "Table, blob, queue storage, Redis. Kusto/KQL"` → tokens `["Table", "blob", "queue storage", "Redis. Kusto/KQL"]`. Same situation.

All three are pure data-source artifacts; the rendering pipeline does what it was told.
